# Tugas 7 Konsep MVC
📌 PENJELASAN TUGAS 7 – PRAKTIKUM PBW B

Pada Tugas 7, kalian diminta membuat program penjualan produk sederhana menggunakan konsep MVC (Model, View, Controller) yang terhubung dengan database MySQL.

1. Struktur Folder

Buat struktur folder sesuai gambar pada slide Tugas 7. Setiap file memiliki fungsi masing-masing:
Model (ProdukModel.php): Mengelola data produk dan berinteraksi dengan database.
View (create.php, edit.php, index.php): Menampilkan halaman tambah produk, edit produk, dan daftar produk.
Controller (ProdukController.php): Menghubungkan Model dengan View serta mengatur proses program.
index.php (utama): Menjadi pintu masuk untuk menjalankan program.
koneksi.php: Menghubungkan PHP dengan database MySQL.

2. Program yang Dibuat

Buat program sederhana yang memungkinkan pengguna untuk:
Menambahkan data produk.
Menampilkan daftar produk.
Mengedit data produk.
Menyimpan perubahan data ke database.
Contoh data produk bisa berupa nama produk, harga, dan stok.

3. Database

Buat database MySQL untuk menyimpan data produk. Pastikan data yang ditambahkan melalui program benar-benar masuk ke database dan dapat ditampilkan kembali.

4. Screenshot Hasil

Sertakan screenshot hasil program yang sudah berhasil dijalankan, seperti halaman daftar produk, form tambah/edit produk, dan data yang tersimpan di database.
